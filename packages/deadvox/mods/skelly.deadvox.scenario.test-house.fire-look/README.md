# Fire look fixture

Start `firelook` with the fire-look mod enabled.

- [ ] The shed's burning wall cells show flames on exposed faces.
- [ ] Nearby surfaces receive fire light.
- [ ] The debug ignition still lights another flammable cell.
- [ ] Waiting for the authored burn duration removes each cell's flame and light.
