# Furniture push-off look

Open the [fixture](/?start-mod=skelly.deadvox.scenario.test-house.furniture-push-look#{debug:true}).

It falls to the ground below instead of refusing at the edge. The rule and reason are in `packages/deadvox/SLICE-5.md`, "Support".
