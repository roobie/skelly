# Vehicle authoring tool

This browser page inspects the vehicle blueprints loaded from Deadvox base content
and downloads a blueprint in the content shape. It makes the established export
boundary available before a full vehicle editor exists. The contract is in
`packages/deadvox/docs/vehicle-spike.md`, "Export contract".
